Machine Learning Roadmap

From programming fundamentals to classical ML, deep learning, generative AI, and production deployment.

10 learning branches Expandable tree Math + Code Beginner → Advanced
00 Programming & Tools
  • Python
    • Variables, data types, loops, functions, OOP, modules
  • NumPy
    • Arrays, vectors, matrices
    • Broadcasting and vectorization
    • Indexing, slicing, array operations
  • pandas
    • DataFrames, filtering, grouping, joins, missing values
  • Visualization: Matplotlib, Seaborn
  • Tools: Jupyter Notebook, Git, GitHub, scikit-learn
01 Mathematics for ML

Linear Algebra

  • Vectors, matrices, dot product
  • Matrix multiplication and transformations
  • Eigenvalues, eigenvectors, Singular Value Decomposition (SVD)

Calculus

  • Derivatives and partial derivatives
  • Gradients and chain rule
$$ \nabla_\theta J(\theta) $$

Probability & Statistics

  • Mean, variance, standard deviation
  • Conditional probability and Bayes' theorem
  • Gaussian distribution
  • Covariance and correlation
  • Maximum likelihood estimation (MLE)
$$ p(x)=\frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} $$

Optimization

  • Objective functions, minima and convergence
  • Learning rate and optimization landscape
02 Data Preparation
  • Data collection, cleaning and validation
  • Exploratory Data Analysis (EDA)
  • Feature engineering
    • Creating and transforming features
    • Polynomial features
    • Feature selection
  • Categorical encoding: one-hot, ordinal
  • Missing-value imputation
  • Feature scaling
    • Standardization (Z-score)
    • Min-Max normalization
  • Train / validation / test split
  • Data leakage prevention
$$ z=\frac{x-\mu}{\sigma} \qquad x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}} $$
03 Core Machine Learning

A. Supervised Learning

  • Regression — predict numbers
    • Linear regression: simple and multiple
    • Polynomial regression
    • Ridge and Lasso regression
    • Evaluation: MAE, MSE, RMSE, R²
  • Classification — predict classes
    • Binary, multiclass and multilabel classification
    • Logistic regression
    • Decision boundaries
    • Confusion matrix
    • Accuracy, precision, recall, F1-score, ROC-AUC
$$ \text{MSE}=\frac{1}{m}\sum_{i=1}^{m} (y_i-\hat y_i)^2 $$

B. Unsupervised Learning

  • Clustering: K-Means, hierarchical, DBSCAN, Gaussian Mixture Models
  • Dimensionality reduction: PCA, SVD, t-SNE, UMAP
  • Anomaly detection

C. Reinforcement Learning

  • Agent and environment
  • States, actions and rewards
  • Markov Decision Process (MDP)
  • Policies and value functions
  • Q-learning and policy gradients
04 How Models Learn
  • Model parameters and hyperparameters
  • Cost / loss functions
    • MSE and MAE
    • Binary cross-entropy
    • Categorical cross-entropy
  • Optimization algorithms
    • Batch Gradient Descent
    • Stochastic Gradient Descent (SGD)
    • Mini-batch Gradient Descent
    • Momentum and RMSProp
    • Adam optimizer
  • Regularization: L1, L2, early stopping
  • Model evaluation and selection
    • Cross-validation
    • Hyperparameter tuning
    • Underfitting and overfitting
    • Bias-variance trade-off
    • Learning curves and error analysis
$$ \theta_{t+1}=\theta_t-\alpha\nabla_\theta J(\theta_t) $$
05 Tree-Based Algorithms
  • Decision trees

  • Ensemble learning
    • Bagging → Random Forest
    • Boosting → AdaBoost
    • Gradient Boosting
    • XGBoost
    • LightGBM and CatBoost
$$ H(S)=-\sum_i p_i\log_2(p_i) $$
06 Other Classical Algorithms
  • K-Nearest Neighbors (KNN)

Neural Network Fundamentals

Training Techniques

Architectures

  • Autoencoders — representation learning

Recommended Learning Path

Programming → Mathematics → Data Preparation → Supervised ML → Optimization → Trees & Ensembles → Deep Learning → Specialization → MLOps
Tip: Build small projects after each major section. Learn unsupervised learning after the supervised fundamentals; study reinforcement learning when you are ready for its separate branch.
